# 明誠 Bus

藤枝明誠中学校・高等学校が公式サイトで公開しているスクールバス情報を、
スマホで確認しやすい形に整理する**非公式Webアプリ**です。

## できること

- 月間カレンダーを上部に表示し、日付を選ぶと下校予定を確認
- 今日の日付と選択中の日付をカレンダー上で表示
- 榛南線のみを掲載
- 通常・変更・特別便・運休・未確認を色分け
- 下校時の学校出発時刻だけを表示（到着時刻は非表示）
- 下校はA便が月〜金の通常便（特別日のA便指定は公式案内を優先）、B便が両校で授業がある日、C便がどちらか一校で授業がある日、D便が両校とも授業がない日に対応
- 変更日は公式PDFの「明誠高校」行から下校便数と学校出発時刻を抽出（学校を通過する便は除外）し、公式PDFへのリンクも表示
- GitHub Actionsで公式サイトを3時間ごとに確認し、今月・翌月の案内だけを保存
- カレンダーは今月と翌月を表示（前月の予定は保持・表示しない）
- 取得失敗時は前回の `schedule.json` を壊さず保持
- 日付と便種別が明記された日だけを確定表示

## 大事な設計

PDFのレイアウトは月ごとに微妙に変わることがあります。
そのためパーサーは「確実に判定できる情報だけ」を自動反映します。

**時刻と日付の対応付けに自信がない場合、通常運行とも変更とも断定しません。**
その日は `未確認` と表示し、公式PDFを開けるようにします。通常ダイヤは参考情報として表示しますが、未確認日の個別乗車時刻は表示しません。

## 公開方法（GitHub Pages）

1. GitHubで新しいリポジトリを作る
2. このZIPの中身をリポジトリ直下へアップロード
3. GitHub の `Settings → Pages` を開き、公開元を `GitHub Actions` に設定
4. `Actions` タブで `Update school bus data` を一度実行
5. 完了後、リポジトリの `Settings → Pages` に表示されるURLを開く

数分後、PagesのURLでアプリが開けます。

## 自動更新

`.github/workflows/update-bus.yml` が3時間ごとに公式サイトを確認し、データ更新後に公開ページも再配信します。通常のファイル変更は `deploy-pages.yml` が公開ページへ反映します。

流れ:

1. 藤枝明誠公式トップページを取得
2. 掲載中の月別「スクールバス ○月変更案内」から今月・翌月分だけを探す
3. 今月・翌月の榛南線PDFだけを取得
4. PDF本文から確実に読める運休 / A・B・C・D便 / 変更日を抽出
5. `data/schedule.json` を今月・翌月分だけに整理し、前月以前の記録を削除
6. 変更があれば自動commit

PDFのカレンダー配置を読み取れない場合、抽出できなかった日付は未確認のままです。必ず公式PDFの案内リンクから確認してください。

## ローカル確認

静的ファイルなので、ルートで以下を実行するだけです。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## 注意

このアプリは学校公式ではありません。
運休・変更など重要な予定は必ず学校公式サイト・公式PDFでも確認してください。
